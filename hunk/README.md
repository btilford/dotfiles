# hunk — interactive diff review TUI

Stow package. `stow --no-folding hunk` from `~/dotfiles`.

| Path | Installs to |
|------|-------------|
| `.config/hunk/config.toml` | `~/.config/hunk/config.toml` |

Split layout, `graphite` theme, line numbers on, untracked files included.
Installed via the `bun` backend in `metapac/.config/metapac/groups/core.toml`.

Claude Code drives live sessions through the `hunk-review` skill — it inspects
the review focus, navigates files and hunks, and posts inline comments.
